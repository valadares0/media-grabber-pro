# ⚡ Media Grabber Pro v5.0 (Cortes Virais IA)

Extensão profissional para Google Chrome com IA para cortes virais automáticos, detecção de vídeos/fotos e trilhas sonoras instrumentais inteligentes.

---

## 💻 Como Instalar no Windows (1 Único Clique)

1. Abra esta pasta no seu outro PC.
2. Dê **duplo clique** em:
   ▶️ **`INSTALAR_EXTENSAO.bat`**
3. Pronto! O robô instala tudo sozinho, inicia o motor e abre o Chrome com a extensão instalada e fixada no topo.

---

## 🍎 Como Instalar no Mac (1 Único Clique)

1. Copie esta pasta para o seu Mac.
2. Dê **duplo clique** em:
   ▶️ **`INSTALAR_NO_MAC.command`** *(ou no aplicativo `INSTALAR_NO_MAC.app`)*
3. Ele vai instalar tudo sozinho automaticamente (Node, FFmpeg, yt-dlp) e abrir o Chrome com a extensão e o estúdio de cortes prontos para usar!
